# Changelog

## 1.1.0 - 2026-11-24

### Added

- **SubD Cage modeling:** edit a low-poly control cage while viewing a live level-2 Catmull–Clark surface.
- **Contextual cage selection:** point, edge, and coplanar face-patch selection is inferred from Pencil hover or touch contact, with direct dragging and Shift-based multi-selection.
- **Topology-aware soft movement:** move connected cage points with an adjustable soft radius, and extrude selected cage faces.
- **Cage X symmetry:** mirror cage-point edits across the selected object's local X plane.
- **Touch modifier controls:** collapsible on-screen Shift, Ctrl, and Alt controls, positioned for left-hand access.

### Improved

- High-DPI rendering on Retina displays, including iPad.
- Apple Pencil input for mesh selection, gizmos, and editing tools.

### Not included yet

- Global edge-loop insertion; this release adds contextual edge selection, not loop cutting.
